**Часть 2: Ветка B, Backend / FastAPI**

## Входные файлы

Положите в корень проекта:

- `transactions.csv`
- `gold_set.csv`
- `categories.json`

## Запуск за 2 команды

pip install -r requirements/local.txt
uvicorn api.main:app --reload

## Тесты

pytest tests/ -v

## Эндпоинты

- GET /counterparty/{id} - карточка контрагента
- GET /search?q=... - поиск с fuzzy-match, фильтры, пагинация
- GET /counterparty/{id}/anomalies - аномалии

## Документация

http://127.0.0.1:8000/docs
